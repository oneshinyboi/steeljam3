# Desert Drive

Desert Drive is an endless runner, or in this case an endless driver game, created in unity as a submission for the University of Sheffield game dev society weekend-long [game jam](https://shefgamedevsoc.github.io/posts/2025-11-17-Game-Jam-25/). The player must avoid cars while simultaneously guessing the code for the lock attached to their door, in order to escape the car and win the game.

## Controls:
### Driving View
- **a** and **d** to move left and right
- **f** to switch to door view
### Door View
- **f** to exit to the driving view
- click the arrows to cycle the numbers on the lock
